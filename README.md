# Personal Economic Trainer

The complete mobile-first interface uses synthetic demo data. It supports transaction exploration, spending scenarios and offline use; it does not connect to a bank.

```sh
npm --prefix complete-ui install
npm run dev:complete
```

Open http://127.0.0.1:3001. Run `npm run build:complete` for a production build and `npm --prefix complete-ui test` for the automated tests. Optional external AI integrations require separate configuration; the default experience works without an API key.
